# GemMiner 2.0 (Forge 1.8.9)

Commands: /hsm set | clear | list | speed <0.5-6> | range <4-32> | preset <color> | debug | dig
Keys (Options > Controls > GemMiner): G mining, H add waypoint, J clear waypoints, L remove last waypoint, K AOTV, B bridging

Flow: reach me aim ke sabse paas ka gemstone mine -> khatam hone par scan + A* raaste se chal ke jaana -> kuch na mile to waypoint.
Build: push to GitHub, Actions tab, download artifact jar -> .minecraft/mods
Use only on servers where automation is allowed.
